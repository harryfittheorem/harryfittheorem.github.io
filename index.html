How it works

Kirtan together, from any device

1

Host selects a Shabad

The Kirtan host browses the library or searches by voice, selects the Shabad, and enters their name to start a session.

2

Sangat joins on their phones

Everyone in the room opens Ek Sur and taps "Join Kirtan." The active session appears immediately — no code or QR needed.

3

Pankti syncs in real time

As the host advances through each line, every Sangat member's screen updates automatically so the whole group stays together.

4

Host ends the session

When Kirtan is complete, the host stops the session. All devices return gracefully to the home screen.
